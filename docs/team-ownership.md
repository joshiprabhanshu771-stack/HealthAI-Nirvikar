# Team Ownership

| Role | Owned folders |
| --- | --- |
| Frontend developer | `frontend/src/pages/`, `frontend/src/assets/`, `frontend/src/components/`, `frontend/src/services/`, `frontend/src/utils/`, `frontend/public/` |

| Database developer | `database/`, `docs/database-documentation.md` |
| AI/ML developer | `backend/src/main/java/com/healthai/service/`, `dto/`, `mapper/`, `util/`, and future model integration modules |

Shared configuration changes should be documented in `docs/architecture.md` and reviewed by the affected owners.
